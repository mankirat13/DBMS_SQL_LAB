📖 About the Repository
This repository contains practical lab assignments for the Database Management System (DBMS) & SQL Lab (BCS552) course offered to Third Year B.Tech Computer Science and Engineering students at Invertis University, Bareilly.

The purpose of this repository is to provide practical experience with SQL (Structured Query Language) and fundamental database management concepts through 15 hands-on assignments.

Each assignment focuses on a specific SQL concept, starting with basic table creation and data manipulation and progressing to advanced operations such as joins, subqueries, views, and indexes.

🎯 Objectives
Understand the fundamentals of relational database management systems.
Learn how to create and manage database tables.
Perform CRUD operations (Create, Read, Update, Delete).
Retrieve and filter records using SQL queries.
Apply aggregate functions and grouping operations.
Understand different types of SQL joins.
Work with subqueries and set operations.
Create and use database views and indexes.
Develop practical SQL query-writing skills.

🚀 Getting Started
Follow these steps to run the SQL assignments:

Clone the repository:

bash
git clone https://github.com/mankirat13/DBMS_SQL_LAB.git
Navigate to the repository:

bash
cd DBMS_SQL_LAB
Open your preferred SQL environment, such as MySQL Workbench, PostgreSQL, or SQLite.
Open the SQL file for the assignment you want to practice.
Execute the SQL statements in the given order.
Verify the output against the expected results provided in the assignment.
📋 Lab Instructions
Complete one assignment in each lab session, following the prescribed order.
Write and execute the SQL queries yourself.
Save the SQL program file and a screenshot or copy of the output for every task.
Include your name, roll number, and assignment number at the beginning of every submission file.
Submit the SQL statements and corresponding execution results for each assignment.
